Zásady ochrany soukromí SysDialu

Tento překlad je poskytován pro usnadnění. Závazné je anglické znění na adrese https://sysdial.app/privacy.html.

Datum účinnosti: 17. listopadu 2026

SysDial je systémový monitor pro lištu menu macOS, vytvořený Oleksandrem Hrabarem („my“, „nás“). Tyto zásady vysvětlují, jak SysDial nakládá s informacemi na vašem Macu. Platí pro obě edice: SysDial ze sysdial.app (Direct) a SysDial z Mac App Store. Platí také pro web sysdial.app.

Stručně

  • SysDial neprodává ani nesdílí osobní údaje a shromažďuje jen to, co je potřeba k provozu vaší licence.
  • Aplikace nemá žádné účty, žádnou analytiku, žádnou reklamu ani sledování uživatelů.
  • Web sysdial.app počítá návštěvy pomocí Cloudflare Web Analytics – bez cookies a bez vaší identifikace.
  • Vše, co SysDial měří, zůstává na vašem Macu.
  • SysDial navazuje jen několik síťových spojení, uvedených níže. Jediné, které se dostane k nám, je kontrola licence v edici Direct, a odesílá jen to, co je potřeba ke kontrole vaší licence.

Co SysDial čte na vašem Macu

Aby mohl zobrazovat své hodnoty, SysDial za běhu čte informace z macOS:

  • hodnoty procesoru, GPU, paměti, disku, baterie, ventilátorů a teploty;
  • síťovou aktivitu: aktuální rychlost a množství přenesených dat;
  • v edici Direct jména, využití procesoru a paměti běžících procesů a aplikací.

Tyto informace se používají pouze k zobrazení v SysDialu a ke spouštění upozornění, která zapnete. Nikdy neopustí váš Mac.

SysDial uchovává malé množství dat, aby mohl zobrazovat historii a pamatovat si vaše nastavení:

Kde jsou tato data uložena:

  • Edice Direct: ~/Library/Application Support/app.sysdial.mac/ a předvolby aplikace (app.sysdial.mac).
  • Edice Mac App Store: uvnitř sandboxového kontejneru aplikace, spravovaného macOS.

Pro smazání všeho ukončete SysDial a odstraňte tato umístění (nebo u edice App Store smažte aplikaci). V Nastavení → O aplikaci volba Zobrazit datovou složku otevře složku za vás.

Síťová spojení

SysDial se připojuje k internetu jen kvůli následujícímu:

  • Veřejná IP adresa. Aby zobrazil vaši veřejnou IP adresu na kartě Síť, SysDial si ji vyžádá z api.ipify.org. Stejně jako jakýkoli web, který navštívíte, tato služba vidí vaši IP adresu v okamžiku požadavku. Můžete to vypnout v Nastavení → Obecné → Zobrazit veřejnou IP.
  • Kontroly kvality internetu (SysDial Pro). Pro měření latence a zjišťování výpadků SysDial otevírá krátká spojení na známé veřejné servery (Cloudflare 1.1.1.1 a Google 8.8.8.8) a vyhledává náhodný název přes váš DNS server. Při těchto kontrolách se neodesílají žádná data o vás ani o vašem Macu; provozovatelé těchto serverů vidí spojení z vaší IP adresy, stejně jako u jakéhokoli jiného spojení.
  • Aktivace a kontrola licence (edice Direct). Když aktivujete SysDial Pro a poté zhruba jednou denně, SysDial kontaktuje náš licenční server na adrese api.sysdial.app. Odesílá váš aktivační kód nebo licenční token, otisk vašeho Macu (jednosměrný hash jeho hardwarového ID, který nelze převést zpět na toto ID; protože je propojen s vaší licencí, považuje se za osobní údaj) a název modelu vašeho Macu, například „MacBook Pro (16-inch, Nov 2023)“, abyste své Macy dokázali rozlišit. Používáme to pouze k započítání, kolik Maců vaši licenci používá, a k vypnutí Pro, pokud jsou za nákup vráceny peníze nebo je licence zrušena. Pokud jste offline, nic se nemění. Běží na Cloudflare a databáze je v EU.

Kromě kontroly licence SysDial neodesílá vaše naměřené hodnoty, historii, jména aplikací ani žádná jiná data nám ani nikomu jinému.

Oprávnění, o která SysDial může požádat

  • Oznámení: k zobrazení upozornění, která zapnete. Oznámení se vytvářejí na vašem Macu.
  • Ovládání Finderu (edice Direct): pouze když kliknete na Vyprázdnit koš v Úložišti, aby mohl Finder vyprázdnit koš.
  • Heslo správce (edice Direct): pouze při resetování indexu Spotlightu. Heslo se zadává v dialogovém okně macOS; SysDial ho nikdy nevidí ani neukládá.

Nákupy

  • Edice Mac App Store: nákupy zpracovává Apple. Nedostáváme vaše platební údaje. Platí zásady ochrany soukromí Applu.
  • Edice Direct: nákupy zpracovává náš poskytovatel plateb, který vystupuje jako prodejce záznamu. Dostáváme pouze to, co je potřeba k vystavení a podpoře vaší licence, například vaši e-mailovou adresu a údaje o licenci. Na samotnou platbu se vztahují zásady ochrany soukromí poskytovatele plateb. Vaši e-mailovou adresu používáme k odeslání aktivačního odkazu a, když o to požádáte, odkazu pro správu vašich Maců. Tyto e-maily se odesílají přes Resend.

Web sysdial.app

Abychom věděli, kolik lidí web navštěvuje a které stránky čtou, používá web Cloudflare Web Analytics. Tato služba nepoužívá cookies, nic neukládá do vašeho prohlížeče a nesleduje vás napříč jinými weby. Zaznamenává otevřenou stránku, web, ze kterého přicházíte, typ prohlížeče a zařízení, vaši zemi a rychlost načtení stránky. Platí zásady ochrany osobních údajů společnosti Cloudflare.

Web je hostován na GitHub Pages. Jako u každého webu vidí GitHub a Cloudflare vaši IP adresu, když prohlížeč stránku načítá. Když si stahujete SysDial, náš server stahování započítá podle dne, verze aplikace a země – vaši IP adresu neukládá. Web nemá žádnou reklamu, žádné další sledovací nástroje ani formuláře.

Poskytovatelé služeb

K provozu SysDialu využíváme několik služeb. Každá zpracovává údaje jen proto, aby nám poskytla svou službu:

  • Cloudflare — provozuje licenční server a jeho databázi (v EU), doménu webu a Web Analytics.
  • Resend — odesílá aktivační e-maily a e-maily o „správě vašich Maců“ (z EU).
  • GitHub — hostuje web.
  • Paddle — prodává SysDial Pro jako merchant of record (oficiální prodejce). U plateb je Paddle samostatným správcem podle vlastních zásad ochrany osobních údajů.

Některé z těchto společností sídlí ve Spojených státech. Pokud údaje opouštějí EU, opírají se o rámec EU–USA pro ochranu údajů (EU–US Data Privacy Framework) nebo o standardní smluvní doložky Evropské komise.

Jak dlouho údaje uchováváme

  • Vaše licence (e-mailová adresa, tarif, Macy a čas, kdy se každý Mac naposledy ohlásil): po dobu platnosti licence a 2 roky po jejím skončení nebo zrušení, abychom vám mohli pomoci s podporou a vrácením peněz. Poté se automaticky smaže.
  • Kopie e-mailů, které odesíláme: text se smaže po 30 dnech; datum, předmět a příjemce zůstávají u vaší licence.
  • Odkazy na „správu vašich Maců“: smažou se po vypršení platnosti (24 hodin).
  • E-maily podpoře: po dobu potřebnou k odpovědi vám.
  • Platební a daňové záznamy: uchovává Paddle jako prodejce, jak vyžaduje zákon.
  • Technické záznamy bez osobních údajů – ID platebních událostí (90 dní), nedokončené nákupy v aplikaci (7 dní) a náš administrátorský log (2 roky) – se mažou automaticky.

Právní základy

  • Aktivace licence, denní kontrola a e-maily k licenci: abychom vám poskytli SysDial Pro, který jste si koupili nebo dostali (plnění smlouvy, GDPR čl. 6 odst. 1 písm. b).

Vaše práva

Můžete nás požádat, abychom vám ukázali údaje, které o vás uchováváme, opravili je, smazali je, předali vám je v přenositelném formátu nebo přestali či omezili jejich používání.
