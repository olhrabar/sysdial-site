# Images

Put these files here (PNG):

- `icon.png` — app icon, 512×512 (Xcode → Assets → AppIcon → the 512pt image, or export from the .icon file).
- `panel.png` — screenshot of the panel opened from the menu bar (⌘⇧4, then Space, click the panel). Dark or light, ~900px wide.
- `window.png` — screenshot of the window on Overview, ~2000px wide.

Until they're added, the page shows neutral placeholders.
